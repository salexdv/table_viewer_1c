# github-release-artifact: план реализации и решения

## 1. План реализации

1. Зафиксировать и согласовать контракт публикации HTML-сборки.
2. Добавить GitHub Actions workflow с релизным и ручным триггерами.
3. Установить зависимости через npm, выполнить существующую production-сборку и подготовить
   `table_viewer.html`.
4. Разделить публикацию: GitHub Release asset для релизного события и Actions Artifact для ручного запуска.
5. Описать доставку готового файла в README.
6. Выполнить локальную сборку, проверить workflow и завершить спецификацию.

## 2. Открытые вопросы

Нет. Имя файла и оба режима запуска утверждены пользователем.
