# selected-cells-api: API получения выделенных ячеек

## 1. Контекст и проблема

Интеграции 1С нужны названия колонок, значения и номера строк текущего выделения.

## 2. Публичный контракт

`window.getSelectedCells()` без аргументов возвращает строгую JSON-строку:

```json
{
  "table": { "index": 0, "id": null, "name": "Остатки" },
  "columns": [{ "index": 1, "id": "quantity", "name": "Количество" }],
  "rows": [{ "number": "2.1", "sourceNumber": "3.2", "cells": [{ "value": 10, "text": "10" }] }]
}
```

- Выделение берётся только из активной вкладки, включая вложенные таблицы.
- Индексы таблицы и колонок исходные, с нуля, внутри активной вкладки; отсутствующие id равны null.
- Колонки идут в порядке visibleColumns с учётом перестановки и закрепления; cells соответствует columns.
- Строки идут в порядке visibleRows; закреплённая строка включается один раз.
- number — показанный номер строки, sourceNumber — исходный путь во входных данных; оба строковые,
  с нумерацией от единицы. Исходный путь сохраняется при сортировке и фильтрации.
- value сохраняет скалярный тип, включая null. Для ссылки возвращается { label, ref }, для вложенной
  таблицы — { label } без её содержимого. text получается через resolveCellDisplay с текущими настройками.
- Без выделения возвращается JSON { "table": null, "columns": [], "rows": [] }.
- До создания приложения и после destroy возвращается false.

## 3. Поведение и ограничения

Снимок строится из модели, включая выделенные ячейки вне отрисованной области. Скрытые колонки,
скрытые, отфильтрованные и свёрнутые строки не добавляются. Чтение не изменяет состояние и не создаёт
событий 1С. Существующие правила сброса выделения сохраняются. Дубли названий колонок допустимы.
Результат не содержит ссылок на изменяемые объекты модели.

## 4. Критерии приёмки

Unit-проверки покрывают направления диапазона, порядок, типы, представления и номера дерева.
Browser-проверки покрывают экспорт, реальные действия выделения, фильтры, сортировку, закрепление,
виртуализацию, вкладки, жизненный цикл и отсутствие событий. Полный гейт — npm test.

## 5. Вне области

Новые события 1С, изменение правил выделения, возврат содержимого вложенных таблиц.
