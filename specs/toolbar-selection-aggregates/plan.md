# toolbar-selection-aggregates: план реализации и решения

## 1. План реализации

1. Перестроить общую панель на адаптивный поиск и три визуально разделённые группы команд.
2. Увеличить кнопки управления деревом и оформить их отдельной группой рядом с масштабом.
3. Добавить единый расчёт пяти агрегатов выделения и popup кнопки `Ʃ`.
4. Применить правое выравнивание к числовым данным и итогам с учётом виртуального переиспользования строк.
5. Обновить unit- и browser-тесты, выполнить полный тестовый гейт и перенести спецификацию в `specs/done`.

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-15 | Ограничить поиск половиной панели только шире 760 px | На узком экране поиск должен оставаться удобным |
| 2026-09-15 | Всегда оставлять `Ʃ` доступной | Popup явно сообщает об отсутствии числового выделения |
| 2026-09-15 | Рассчитывать пять функций одним проходом | Исключает повторный обход крупного выделения |
| 2026-09-15 | Выравнивать только данные и итоги | Заголовки и фильтры сохраняют привычную компоновку |
