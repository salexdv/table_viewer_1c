# table-viewer-controls: Агрегаты, фильтры значений и управление диапазоном строк

## 1. Контекст и проблема

Просмотрщик показывает техническую ошибку до подстановки данных, выделяет номера строк красным и поддерживает
только сумму. Текстового фильтра недостаточно для быстрого отбора известных значений, а в больших плоских
таблицах нельзя временно скрыть строки до или после интересующего диапазона.

## 2. Область изменений

Изменяются модель агрегатов и фильтрации, состояние представления, заголовки и итоговые строки grid, панель
выделения, контекстное меню, стартовое состояние, стили, тесты и документация поведения.

## 3. Поведение

### 3.1. Ожидание и оформление

- Незаменённый `_DATA_` показывает по центру окна `Ожидение данных...` с `role="status"`, не считается ошибкой
  в консоли и оставляет результат `init()` равным `false`.
- Ошибки JSON и структуры сохраняют диагностический блок и запись в консоль.
- Номера строк имеют обычное начертание и нейтральный цвет. `№` и `Итого` наследуют стили своих строк.

### 3.2. Агрегаты

- Для чисел доступны `Сумма`, `Среднее`, `Минимум`, `Максимум` и `Количество`; по умолчанию выбрана сумма.
- Кнопка `ƒ` числовой или процентной колонки выбирает функцию её итоговой ячейки.
- Аналогичный селектор в правой части общей панели управляет результатом выделенного диапазона.
- Агрегаты учитывают только показанные строки. Для пустого набора сумма и количество равны нулю, остальные
  функции показывают `—`.
- Однородные проценты форматируются со знаком `%`; смешанные числа и проценты — как обычное число.

### 3.3. Фильтр значений

- Текстовый фильтр сохраняется. Независимый popup содержит поиск вариантов, массовый выбор, чекбоксы,
  применение, отмену и очистку.
- Значения одной колонки объединяются через OR, остальные виды фильтрации — через AND.
- Варианты учитывают глобальный поиск и фильтры других колонок, но игнорируют оба фильтра своей колонки.
- Уникальность и точное сравнение определяются отображаемым текстом. Пустое значение подписывается
  `(Пустые)`, boolean отображается как `Да`/`Нет`, ссылки группируются по подписи.
- Варианты сортируются по типу колонки, пустое значение следует последним. Список виртуализирован для 10 000
  уникальных значений. Фильтрация дерева сохраняет цепочку предков совпавшего узла.

### 3.4. Диапазон строк

- В контекстном меню плоской таблицы доступны `Свернуть строки до` и `Свернуть строки после`.
- Выбранная строка остаётся видимой; две команды можно совместить, оставив интервал.
- Сверху и снизу появляются элементы `Показать N скрытых строк`, возвращающие соответствующую часть.
- Скрытые строки исключаются из счётчика, выделения и агрегатов, даже если были закреплены.
- Диапазон сбрасывается при сортировке, фильтрации, глобальном поиске, командах раскрытия/сворачивания и новой
  загрузке данных, но сохраняется при масштабе, resize и настройке видимости колонок.
- В древовидных таблицах команды диапазона отсутствуют.

### 3.5. Граничные случаи и ошибки

- Пустой выбор значений скрывает все строки; выбор всех доступных вариантов снимает фильтр значений.
- Активные значения, временно недоступные из-за других фильтров, сохраняются до очистки или повторного применения.
- Все пользовательские значения выводятся только через `textContent`.

## 4. Публичные контракты

Формат `Data`, функции на `window`, очередь `{ event, params }` и события 1С не меняются. Новые параметры состояния
существуют только в памяти документа. Production остаётся единым автономным `dist/index.html` уровня ES2015.

## 5. Критерии приёмки

- [ ] Стартовый `_DATA_` показывает ожидание, а некорректные данные — диагностическую ошибку.
- [ ] Номера строк нейтральные и без полужирного начертания.
- [ ] Пять агрегатов работают для колонок и выделения с корректным форматированием пустых наборов и процентов.
- [ ] Текстовые фильтры и фильтры значений независимо объединяются по заданным правилам.
- [ ] Popup значений остаётся ограниченным по числу DOM-узлов на 10 000 значений.
- [ ] Плоская таблица скрывает и возвращает диапазоны до/после выбранной строки; дерево не показывает команды.
- [ ] Unit- и browser-тесты проходят; сборка остаётся self-contained и совместимой с ES2015.

## 6. Вне области

- Изменение входной схемы, публичного API или событий 1С.
- Хранение настроек между загрузками документа.
- Расширенные статистические функции и диапазонное скрытие ветвей дерева.
