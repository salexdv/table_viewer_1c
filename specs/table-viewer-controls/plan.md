# table-viewer-controls: план реализации и решения

## 1. План реализации

1. Добавить в модель универсальный расчёт агрегатов, фильтры-множества значений, построение вариантов и срез
   видимых строк; покрыть чистые функции unit-тестами.
2. Добавить селекторы агрегатов, popup значений и элементы возврата скрытых строк в виртуальный grid.
3. Заменить стартовую ошибку плейсхолдера состоянием ожидания, нейтрализовать оформление номеров строк, добавить
   resize нумерации и подбор начальной ширины колонок по содержимому.
4. Расширить browser smoke сценариями новых элементов и проверкой ограниченного DOM списка значений.
5. Обновить документацию, выполнить `npm test`, перевести спецификацию в `done` и перенести её каталог.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-14 | Поддерживать пять базовых агрегатов | Покрывает основные сценарии без перегрузки интерфейса |
| 2026-09-14 | Объединять текстовый фильтр и список значений через AND | Оба способа остаются независимыми |
| 2026-09-14 | Строить варианты с учётом остальных фильтров | Соответствует поведению фильтра Excel |
| 2026-09-14 | Скрывать диапазоны только в плоских таблицах | Не разрывает визуальную структуру дерева |
| 2026-09-14 | Сбрасывать диапазон при смене представления | Исключает неоднозначные границы после сортировки и фильтрации |
| 2026-09-14 | Подбирать ширины по всему набору с верхней границей | Содержимое видно лучше, но единичная длинная строка не ломает компоновку |
