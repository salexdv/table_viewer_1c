# cell-text-wrapping: план реализации и решения

## 1. План реализации

1. Добавить глобальный переключатель с inline SVG, доступными атрибутами и вжатым состоянием.
2. Подключить CSS-режим переноса только к ячейкам данных.
3. Расширить виртуализацию измеряемыми высотами, префиксными смещениями и сохранением scroll-anchor.
4. Инвалидировать измерения при изменении геометрии и покрыть поведение browser smoke-тестами.
5. Обновить README, выполнить полный тестовый гейт и перенести спецификацию в `specs/done`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-16 | Переносить только ячейки данных | Заголовки и служебные строки сохраняют компактную геометрию |
| 2026-09-16 | Показывать текст полностью без лимита строк | Соответствует ожидаемому поведению переключателя переноса |
| 2026-09-16 | Хранить режим только в памяти `ViewerApp` | Публичный формат настроек остаётся обратно совместимым |
| 2026-09-16 | Измерять только виртуализированные строки | Сохраняет работу на наборах из 10 000 строк |
