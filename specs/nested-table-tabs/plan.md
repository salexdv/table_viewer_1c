# nested-table-tabs: план реализации и решения

## 1. План реализации

1. Выделить разбор одной таблицы и добавить итеративную валидацию вложенных таблиц, новый предикат ячейки и
   текстовое представление по `label`.
2. Ввести контекст вкладки с данными, состояниями таблиц, поиском и сохранёнными позициями прокрутки.
3. Добавить панель вкладок, открытие по источнику-ячейке, переключение, закрытие и очистку при `setData`.
4. Разделить внутренние команды активной вкладки и прежние публичные команды исходной вкладки.
5. Дополнить стили светлой и тёмной темы, unit/browser-тесты и документацию интеграции.
6. Выполнить `npm test`, перевести спецификацию в `done` и перенести каталог в `specs/done/`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-28 | Повторный клик активирует вкладку той же ячейки | Не создавать дубликаты одного источника |
| 2026-09-28 | Исходная вкладка не закрывается | Сохранить постоянную точку возврата |
| 2026-09-28 | Заголовок берётся из `table.name` с fallback на `label` | Показывать предметное имя вложенной таблицы |
| 2026-09-28 | Вложенность не ограничивается одним уровнем | Один формат должен работать рекурсивно |
| 2026-09-28 | Закрытие родителя не закрывает дочерние вкладки | Открытая вкладка является самостоятельным рабочим контекстом |
| 2026-09-28 | Публичный API и Settings относятся к исходной вкладке | Не нарушать контракт существующей интеграции 1С |
