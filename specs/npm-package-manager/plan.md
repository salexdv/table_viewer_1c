# npm-package-manager: план реализации и решения

## 1. План реализации

1. Зафиксировать утверждённый контракт перехода на npm.
2. Заменить вызовы pnpm в сценариях и закрепить npm в `package.json`.
3. Сформировать `package-lock.json` без обновления диапазонов зависимостей и удалить lock-файл pnpm.
4. Обновить README, документацию интеграции, сообщения тестов и инструкции репозитория.
5. Выполнить поиск устаревших ссылок и запустить полный доступный гейт через npm.
6. Отметить критерии приёмки, завершить и перенести спецификацию.

## 2. Открытые вопросы

Нет. Переход на npm прямо утверждён пользователем.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-14 | Использовать npm и `package-lock.json` | npm поставляется вместе с Node.js и достаточен для этого проекта |
| 2026-09-14 | Сохранить Node.js 20+ | Требование runtime не связано с выбором менеджера пакетов |
| 2026-09-14 | Не менять диапазоны зависимостей | Переход ограничен инструментом установки и запуска сценариев |
