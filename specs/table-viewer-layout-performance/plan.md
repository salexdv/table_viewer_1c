# table-viewer-layout-performance: план реализации и решения

## 1. План реализации

1. Сжать команды панели и скрыть экспорт без удаления обработчика.
2. Добавить пропорциональное заполнение ширины и адаптивную высоту одной видимой таблицы.
3. Перевести виртуальное тело на покадровый переиспользуемый пул строк и делегированные обработчики.
4. Расширить browser smoke проверками геометрии, доступности и отсутствия полной пересборки при прокрутке.
5. Обновить документацию, выполнить полный тестовый гейт и перенести спецификацию в `specs/done`.
