# visible-rows-api: API получения видимых строк активной вкладки

## 1. Контекст и проблема

Интеграции 1С нужен снимок текущего представления всех таблиц активной вкладки независимо от выделения.

## 2. Публичный контракт

`window.getVisibleRows()` без аргументов возвращает JSON-строку `{ "tables": [snapshot] }`.
Каждый snapshot имеет формат `getSelectedCells()`: `{ table: { index, id, name }, columns: [{ index, id, name }],
rows: [{ number, sourceNumber, cells: [{ value, text }] }] }`.

- Таблицы идут в исходном порядке только активной вкладки; индексы таблиц относятся к этой вкладке.
- Индексы таблиц и колонок исходные, с нуля; отсутствующие id равны null.
- Колонки только видимые, в текущем порядке с учётом перестановки и закрепления; cells соответствует columns.
- Строки идут в порядке visibleRows после поиска, фильтров, сортировки, раскрытия дерева, ограничения диапазона
  и ручного скрытия. Прокрутка и виртуализация не ограничивают снимок. Закреплённые строки включаются один раз.
- Свёрнутые целиком, пустые и полностью отфильтрованные таблицы сохраняют метаданные и колонки с rows: [].
- Итоги и маркеры восстановления строк не включаются. При отсутствии видимых колонок строки имеют cells: [].
- number — показанный номер, sourceNumber — исходный путь строки; строки с нумерацией от единицы.
- value сохраняет скалярный тип, включая null; ссылка копируется как { label, ref }, вложенная таблица —
  как { label } без содержимого. text учитывает текущие настройки представления через resolveCellDisplay.
- Пустая вкладка возвращает JSON { "tables": [] }; до создания приложения и после destroy — false.

## 3. Поведение и ограничения

Синхронное чтение не зависит от выделения, не изменяет состояние и не создаёт событий 1С.
Снимок не содержит ссылок на изменяемые объекты модели. Контракт getSelectedCells сохраняется.
Сборка остаётся автономной и совместимой с ES2015 и старым WebKit.

## 4. Критерии приёмки

Unit: порядок, типы, представления, номера дерева, пустые снимки и регрессия getSelectedCells.
Browser: несколько таблиц, вкладки, фильтры, сортировка, скрытие и диапазоны, сворачивание, закрепление,
виртуализация, независимость от выделения и прокрутки, жизненный цикл и отсутствие событий. Гейт: npm test.

## 5. Вне области

Новые события 1С, выгрузка неактивных вкладок и рекурсивная выгрузка содержимого вложенных таблиц.
