# hide-theme-button-api: план реализации и решения

## 1. План реализации

1. Добавить в приложение состояние скрытия и ссылку на группу темы, применять скрывающий класс при каждой
   отрисовке и очищать состояние при уничтожении экземпляра.
2. Реализовать идемпотентный метод приложения и экспортировать `window.hideThemeButton`.
3. Описать контракт в документации API и интеграции с 1С.
4. Вручную проверить жизненный цикл метода, выполнить production-сборку и завершить спецификацию.

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-16 | Использовать односторонний `hideThemeButton()` без аргументов | Интеграции требуется только скрытие кнопки |
| 2026-09-16 | Скрывать всю группу `.toolbar-theme-group` отдельным CSS-классом | Группа не должна занимать место в панели |
| 2026-09-16 | Хранить состояние в экземпляре `ViewerApp` | Скрытие переживает перерисовки, но сбрасывается новым `init()` |
| 2026-09-16 | Не включать видимость в Settings | Это настройка интеграции, а не пользовательского представления |
| 2026-09-16 | Не добавлять автоматические тесты | Явное ограничение задачи |
