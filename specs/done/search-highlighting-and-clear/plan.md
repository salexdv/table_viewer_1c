# search-highlighting-and-clear: план реализации и решения

## 1. План реализации

1. Выделить в модели разбор запроса, проверку упорядоченных фрагментов и расчёт диапазонов подсветки; подключить
   единый matcher к глобальному и колонковому поиску.
2. Добавить безопасную отрисовку подсвеченного текста для обычных и ссылочных ячеек с учётом совпадения самой
   строки, фильтров колонки и переиспользования виртуальных строк.
3. Построить общий search-control с явной кнопкой очистки для глобального поиска, фильтров колонок и поиска
   значений; добавить совместимые стили и доступные имена.
4. Расширить unit- и browser-тесты, документацию интеграции и ручной чек-лист, затем выполнить полный гейт.
5. Перевести спецификацию в `done` и перенести её в `specs/done/search-highlighting-and-clear/`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-15 | Искать фрагменты в порядке запроса внутри одной ячейки | Исключает неоднозначные совпадения между колонками |
| 2026-09-15 | Подсвечивать только полностью совпавшие ячейки | Предки дерева и частичные совпадения не выглядят найденными |
| 2026-09-15 | Использовать явные кнопки очистки | WebKit 1С ненадёжно формирует события нативного креста |
| 2026-09-15 | Не менять поиск списка значений | Для него требуется только совместимая очистка |
| 2026-09-15 | Завершить реализацию после полного автоматического гейта | Unit-, build- и browser-проверки покрывают контракт |
