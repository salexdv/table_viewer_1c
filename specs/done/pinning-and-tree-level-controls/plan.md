# pinning-and-tree-level-controls: план реализации и решения

## 1. План реализации

1. Расширить строгий parser, снимок и применение настроек двумя упорядоченными массивами фиксации.
2. Добавить преобразование исходных 1-based ссылок строк во внутренние 0-based пути и раздельный сброс при
   отсутствующей цели.
3. Добавить общий пункт снятия фиксации и компактные кнопки уровней дерева.
4. Покрыть модель unit-тестами, а взаимодействие, встроенные настройки и round-trip — browser smoke.
5. Обновить README, API и чек-лист интеграции 1С; выполнить полный локальный гейт.
6. Перевести спецификацию в `done` и перенести в `specs/done/pinning-and-tree-level-controls/`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-16 | Хранить строки и колонки независимыми массивами | Сохраняет существующую модель нескольких фиксаций и их порядок |
| 2026-09-16 | Использовать исходные 1-based номера и пути строк | Формат понятен интеграции и не зависит от сортировки и фильтров |
| 2026-09-16 | Использовать `id` колонки с индексным fallback | Совмещает устойчивость нового формата с прежними строковыми колонками |
| 2026-09-16 | При пропавшей цели очищать только соответствующий вид фиксации | Не теряет независимые корректные настройки строк или колонок |
| 2026-09-16 | Сохранить версию настроек 1 | Старые снимки остаются совместимыми, новые поля являются необязательными |
| 2026-09-16 | Завершить реализацию после полного `npm test` | Unit-, build-, ES2015- и browser-проверки прошли |
