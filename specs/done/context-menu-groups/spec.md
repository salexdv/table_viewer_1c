# context-menu-groups: Группы контекстного меню и сворачивание строк

## 1. Контекст и проблема

Штатные команды контекстного меню выводятся плоским списком без смысловых групп. Нельзя скрыть выделенный
диапазон строк, команды диапазона недоступны для дерева, а уровень раскрытия дерева задаётся только вручную или
сразу для всего дерева.

## 2. Область изменений

Изменяются построение и оформление контекстного меню, модель временно скрытых строк, виртуальный вывод маркеров,
управление раскрытием дерева, автоматические тесты и документация. Публичный JavaScript API, формат данных и
события 1С не меняются.

## 3. Поведение

### 3.1. Группы меню

- Для ячейки данных первым выводится `Отбор по значению`, затем отдельная группа фиксации в порядке строка,
  колонка и подменю `Сворачивание` с командами `Свернуть выделенные`, `Свернуть до`, `Свернуть после`.
- Для дерева после сворачивания выводится подменю `Уровень группировки`.
- Пользовательские команды `addContextMenuItem` выводятся последней отдельной группой в порядке регистрации и
  только для ячеек данных.
- Группы разделяются визуальными разделителями без ведущих, замыкающих и сдвоенных разделителей.
- Названия фиксации отражают текущее состояние: `Зафиксировать` или `Открепить`.
- Подменю открывается наведением, фокусом или нажатием, остаётся в границах окна и закрывается вместе с меню по
  внешнему клику или `Escape`.

### 3.2. Скрытие строк

- Если строка вызова входит в диапазон строк текущего прямоугольного выделения, `Свернуть выделенные` скрывает
  все строки этого диапазона. Иначе скрывается только строка вызова.
- Каждый последовательный скрытый диапазон заменяется маркером `Показать N скрытых строк`. Нажатие маркера
  восстанавливает только соответствующий диапазон; соседние диапазоны объединяются.
- Скрытые строки исключаются из счётчика, выделения и агрегатов. Закреплённая скрытая строка исчезает и после
  восстановления снова выводится закреплённой.
- `Свернуть до` и `Свернуть после` сохраняют текущую семантику и работают также по плоскому списку видимых строк
  дерева.
- Произвольно скрытые строки хранятся отдельно от окна строк и состояния свёрнутых ветвей. Они сбрасываются
  вместе с окном при сортировке, фильтрации, поиске, изменении раскрытия дерева, глобальных командах и загрузке
  данных, но сохраняются при масштабе, resize, настройке колонок и фиксации.

### 3.3. Уровень группировки дерева

- Корневые строки имеют уровень 1. Подменю содержит `Уровень 1` … `Уровень N`, где N — максимальная глубина
  полного дерева.
- Выбор уровня K раскрывает ветви уровней меньше K и сворачивает ветви уровня K и глубже. Максимальный уровень
  раскрывает всё дерево.
- Активная фильтрация продолжает временно раскрывать совпадения и их предков; выбранное состояние сворачивания
  применяется после очистки фильтра.

### 3.4. Граничные случаи и ошибки

- Условно отсутствующие группы не оставляют лишних разделителей.
- Последовательные повторные скрытия корректно образуют несколько маркеров или объединяют соседние.
- Все пользовательские подписи выводятся только как текст. Реализация сохраняет ES2015-floor и не использует
  рекурсию для деревьев практической неограниченной глубины.

## 4. Публичные контракты

Функции на `window`, формат `Data`, очередь `{ event, params }`, события 1С и единый автономный
`dist/index.html` остаются без изменений. Новое состояние существует только в памяти документа.

## 5. Критерии приёмки

- [x] Порядок групп, разделителей и подменю соответствует спецификации для таблицы, дерева и номера строки.
- [x] Скрытие выделения, объединение диапазонов и точечное восстановление работают с виртуализацией и фиксацией.
- [x] Команды `до/после` работают в таблице и дереве.
- [x] Уровни 1, промежуточный и N корректно управляют неровным и глубоким деревом.
- [x] Пользовательские команды сохраняют порядок, payload и безопасный текстовый вывод.
- [x] Unit-, build- и browser-проверки проходят; production остаётся автономной и соответствует ES2015.

## 6. Вне области

- Новые публичные функции, события 1С или изменение входной схемы.
- Постоянное хранение состояния меню, скрытых строк или уровня группировки.
- Полная клавиатурная навигация по пунктам меню.
