# visible-rows-api: план реализации и решения

## 1. План реализации

1. Зафиксировать draft, затем approved на основании запроса пользователя реализовать согласованный план.
2. Выделить общий построитель снимка в модели; добавить API приложения и экспорт window.getVisibleRows.
3. Добавить unit и browser проверки и описание API с примером 1С.
4. Выполнить npm test, отметить done и перенести спецификацию в specs/done/visible-rows-api.

## 4. Результат

Реализованы общий построитель снимка модели и window.getVisibleRows(), сохранён контракт getSelectedCells.
Документация API и интеграции содержит формат и примеры вызова из 1С.

Полный npm test пройден: 50 unit-тестов, production single-file, ES2015 и browser smoke.
Для browser smoke на Windows задан CHROME_PATH установленного Google Chrome; запуск выполнен вне sandbox
после ошибки запуска временного профиля внутри sandbox.
Browser-сценарии проверяют фильтры, сортировку, сворачивание таблиц и ветвей, скрытие и диапазоны,
закрепление, 400 виртуализированных строк, выделение, прокрутку, вкладки, жизненный цикл и отсутствие событий.
