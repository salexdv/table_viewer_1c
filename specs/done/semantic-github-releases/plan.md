# semantic-github-releases: план реализации и решения

## 1. План реализации

1. Зафиксировать и согласовать контракт SemVer-релизов и состав публикуемых файлов.
2. Добавить manifest-конфигурацию Release Please для корня репозитория.
3. Объединить управление релизом, сборку HTML и загрузку assets в одном workflow.
4. Начать отслеживать тестовый EPF как бинарный файл, сохранив игнорирование остальных `tests/*.epf`.
5. Описать Conventional Commits, Release PR и релизные файлы в README.
6. Проверить конфигурацию, полный локальный гейт и условия публикации, затем завершить спецификацию.

## 2. Открытые вопросы

Нет. Формат тегов, охват первого changelog, отсутствие commitlint и хранение EPF в Git утверждены
пользователем.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-16 | Использовать Release Please с Node.js manifest | Стратегия обновляет changelog и оба package-файла |
| 2026-09-16 | Публиковать теги `vX.Y.Z` | В репозитории один выпускаемый продукт |
| 2026-09-16 | Задать первый релиз footer `Release-As: 1.0.0` | Одноразовая фиксация версии не влияет на будущие релизы |
| 2026-09-16 | Включить всю историю в первый changelog | Первый публичный релиз документирует существующие возможности |
| 2026-09-16 | Хранить `TestTableViewer.epf` непосредственно в Git | Файл мал и должен быть доступен в чистом checkout релизного SHA |
| 2026-09-16 | Загружать assets в том же workflow | Релиз от `GITHUB_TOKEN` не запускает отдельный release workflow |
| 2026-09-16 | Оставить ручной и `release.published` режимы | Сохраняется прежний контракт доставки и возможность проверки |
| 2026-09-16 | Не добавлять commitlint | Соблюдение Conventional Commits документируется без нового инструментария |
| 2026-09-16 | Спецификация утверждена пользователем | Пользователь явно запросил реализацию согласованного плана |

## 4. Результаты проверки

- JSON-конфигурация и YAML workflow разобраны программно; подтверждены три триггера, необходимые permissions,
  outputs Release Please, Node.js-стратегия, корневой package и формат тегов без component.
- `tests/TestTableViewer.epf` имеет размер 57 906 байт, доступен в чистом `git archive` и помечен атрибутом
  `binary` (`diff`, `merge` и `text` unset).
- `npm run test:unit` завершился успешно: 33 теста.
- `npm run build` создал автономный `dist/index.html` размером 96 КиБ; проверки single-file и ES2015 прошли.
- `npm run test:browser` запускает Chromium, но останавливается на существующем ожидании gap `8 px`: после
  коммита `b9925d0`, добавившего `.collapse-tree-button { margin-left: 3px; }`, фактический gap равен `11 px`.
  Код и тест просмотрщика в этой спецификации не изменялись.
- GitHub-hosted проверка Release PR, тега `v1.0.0` и обоих assets выполняется после отправки коммитов в
  `master`; implementation-коммит содержит `Release-As: 1.0.0`.
