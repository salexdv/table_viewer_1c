# selected-cells-api: план реализации и решения

## 1. План реализации

1. Согласовать спецификацию и установить in-progress перед изменением кода.
2. Добавить построение снимка в модель и экспорт getSelectedCells через приложение и window.
3. Описать JSON-контракт и вызов из 1С в docs/api.md.
4. Добавить unit/browser-проверки, выполнить npm test.
5. Установить done и перенести спецификацию в specs/done/selected-cells-api/.

## 2. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-10-22 | JSON-строка, активная вкладка, исходные значения и текст, оба номера строки | План явно согласован пользователем запросом на реализацию |

## 3. Проверки

Одиночная ячейка и обратный прямоугольник; типы и представления; дерево после сортировки и фильтрации;
скрытые и закреплённые строки/колонки; большой диапазон; несколько таблиц и вкладок; сброс и destroy.

## 4. Результат

Реализован window.getSelectedCells() и снимок модели с обоими номерами строк и текущим представлением.
Контракт и пример разбора JSON из 1С описаны в docs/api.md.
Итоговый npm test пройден: 46 unit-тестов, production-сборка, single-file/ES2015 и Chromium smoke.
Для браузерной проверки использован установленный Chrome через CHROME_PATH.
