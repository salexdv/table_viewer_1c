# cell-text-wrapping: перенос текста в ячейках

## 1. Контекст и проблема

Значения ячеек сейчас всегда выводятся одной строкой с многоточием. Длинный текст нельзя прочитать целиком без
изменения ширины колонки, хотя таблицы должны поддерживать режим переноса текста, знакомый пользователям Excel.

## 2. Область изменений

- Глобальная пиктограммная кнопка переноса текста в панели инструментов.
- Многострочное отображение ячеек данных всех таблиц.
- Виртуализация строк переменной высоты без снятия ограничения на число DOM-строк.
- Browser-проверки доступности, геометрии и производительности.

## 3. Поведение

### 3.1. Переключатель

- Кнопка располагается после `Колонки` в той же группе. Существующий разделитель перед командами
  `Свернуть все` и `Развернуть все` сохраняется.
- Кнопка не содержит видимого текста и показывает встроенную SVG-пиктограмму строк с загнутой стрелкой.
- `title` и `aria-label` равны `Переносить текст`; состояние задаётся `aria-pressed` и визуально вжатым стилем.
- По умолчанию перенос выключен. Режим глобален для всех таблиц текущего экземпляра приложения.
- Режим сохраняется при `setData`, `setSettings` и повторной отрисовке. Новый `init`, `destroy` или перезагрузка
  документа возвращают значение по умолчанию.

### 3.2. Ячейки и высота строк

- При включении значения обычных и закреплённых строк переносятся по ширине колонки и полностью видны.
- Длинные непрерывные значения также могут быть разорваны. Ограничения числа строк нет.
- Перенос применяется ко всем ячейкам данных независимо от типа значения, включая ссылки и числа.
- Заголовки, фильтры, номера строк и итоговые ячейки остаются однострочными.
- При выключении восстанавливаются фиксированная высота строк, многоточие и существующий быстрый путь
  виртуализации.

### 3.3. Виртуализация

- В режиме переноса измеряются только отрисованные строки. Для остальных используется однострочная высота как
  начальная оценка.
- Высоты и префиксные смещения определяют размер виртуального тела и видимый диапазон; поиск начала диапазона
  выполняется по вертикальной позиции.
- После уточнения размеров позиции строк и виртуального тела обновляются без полного рендера набора данных.
- Пул DOM-строк остаётся ограниченным и переиспользуется при обычной и быстрой прокрутке.
- Закреплённые строки измеряются отдельно. Маркеры скрытых диапазонов сохраняют фиксированную высоту.
- Изменение ширины или видимости колонок, масштаба, окна, фильтров, сортировки и набора данных сбрасывает
  измерения. Пересчёт ширины объединяется по кадрам, а логическая верхняя строка прокрутки сохраняется.

### 3.4. Граничные случаи и ошибки

- Пустые таблицы и таблицы без видимых колонок продолжают отображаться без ошибок.
- Выделение, ссылки, подсветка поиска, закрепление строк и колонок продолжают работать в обоих режимах.
- Все пользовательские значения по-прежнему выводятся только через `textContent`.

## 4. Публичные контракты

Форматы `Data` и `Settings`, функции `window.*`, очередь `{ event, params }` и события 1С не меняются. Режим не
входит в `getSettings`/`setSettings`. Production остаётся автономным `dist/index.html` уровня ES2015 без внешних
ресурсов.

## 5. Критерии приёмки

- [x] Кнопка стоит после `Колонки`, не содержит текста, доступно подписана и визуально показывает состояние.
- [x] Длинные фразы и непрерывные значения полностью видны в обычных и закреплённых строках.
- [x] Заголовки, фильтры, номера и итоги остаются однострочными; выключение возвращает исходный вид.
- [x] Изменения ширины, масштаба и окна корректно пересчитывают высоты без наложений и потери позиции.
- [x] Таблица на 10 000 строк сохраняет ограниченный пул DOM-узлов и прокручивается до последней строки.
- [x] Unit-, browser- и production-проверки проходят; сборка остаётся self-contained и совместимой с ES2015.

## 6. Вне области

- Настройка переноса отдельно для таблиц, колонок или строк.
- Ограничение числа строк текста и ручное изменение высоты строк.
- Сохранение режима в публичном JSON настроек или новом событии 1С.
