# context-menu-submenus: план реализации и решения

## 1. План реализации

1. Заменить плоскую последовательность пользовательского меню деревом верхнеуровневых элементов и дочерних
   последовательностей подменю.
2. Добавить регистрацию подменю и необязательную адресацию пунктов и разделителей по имени.
3. Обобщить построение пользовательских групп и вывести непустые подменю через существующий механизм вложенного
   меню.
4. Экспортировать `addContextMenuSubmenu` непосредственно на `window` и сохранить совместимость старых вызовов.
5. Расширить browser smoke проверками API, порядка, нормализации, событий, безопасности и жизненного цикла.
6. Обновить документацию API и интеграции 1С, выполнить `npm test`.
7. Перевести спецификацию в `done` и перенести её в `specs/done/context-menu-submenus/`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-17 | Регистрировать подменю только явным вызовом | Ошибочные ссылки обнаруживаются сразу и не меняют порядок меню |
| 2026-09-17 | Использовать видимую подпись как уникальное имя | Сохраняет простой вызов из 1С без отдельного идентификатора |
| 2026-09-17 | Определять позицию вызовом регистрации подменю | Порядок верхнего уровня не зависит от времени добавления дочерних команд |
| 2026-09-17 | Поддерживать только один уровень вложенности | Соответствует требуемому API и существующему механизму подменю |
| 2026-09-17 | Не выводить пустые подменю | Исключает недоступные пустые элементы интерфейса |

Реализация завершена; unit-тесты, автономная production-сборка, проверка ES2015 и browser smoke пройдены.
