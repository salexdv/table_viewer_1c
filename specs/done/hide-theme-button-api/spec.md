# hide-theme-button-api: API скрытия кнопки темы

## 1. Контекст и проблема

Интеграции 1С может требоваться управлять темой только программно и не показывать пользователю кнопку её
переключения. Сейчас группа кнопки темы всегда присутствует в общей панели и не управляется публичным API.

## 2. Область изменений

- Односторонний публичный метод `hideThemeButton`.
- Скрытие всей группы `.toolbar-theme-group` в общей панели.
- Сохранение скрытия при перерисовках текущего экземпляра приложения.
- Документация JavaScript API и интеграции с 1С.

## 3. Поведение

### 3.1. Основной сценарий

- `hideThemeButton()` немедленно скрывает группу кнопки темы и возвращает `true`.
- Повторный вызов безопасен, не меняет другое состояние и также возвращает `true`.
- Скрытие сохраняется после успешных `setData()` и `setSettings()`, которые перестраивают общую панель.
- Новый `init()` создаёт приложение с видимой кнопкой темы. `destroy()` удаляет состояние скрытия вместе с
  остальным состоянием экземпляра.
- Скрытая кнопка не мешает переключать тему через `setTheme`, `setSettings` или `Data.settings`.

### 3.2. Граничные случаи и ошибки

- Если тулбар ещё не построен, но экземпляр приложения уже существует, вызов запоминает скрытие для следующей
  успешной отрисовки и возвращает `true`.
- До создания приложения и после `destroy()` публичный метод возвращает `false`.
- Метод не добавляет обратную операцию показа и не изменяет текущую тему.

## 4. Публичные контракты

```js
hideThemeButton() // boolean
```

Метод экспортируется непосредственно на `window`. Видимость кнопки не входит в Settings, формат данных и
события 1С не меняются. Production-сборка остаётся одним автономным `dist/index.html`.

## 5. Критерии приёмки

- [x] Вызов скрывает всю `.toolbar-group.toolbar-theme-group` и возвращает `true`.
- [x] Повторный вызов идемпотентен.
- [x] `setData()` и `setSettings()` не возвращают скрытую группу.
- [x] Новый `init()` возвращает исходно видимую группу.
- [x] Скрытая кнопка не влияет на программное переключение и сохранение темы.
- [x] API и пример вызова из 1С документированы, production-сборка проходит.

## 6. Вне области

- Публичный метод обратного показа кнопки.
- Сохранение видимости в Settings или входных данных.
- Скрытие других групп общей панели.
- Добавление или изменение автоматических тестов.
