# table-viewer: план реализации и решения

## 1. План реализации

1. Зафиксировать SDD, правила репозитория и утверждённый контракт.
2. Настроить Webpack и self-contained production-сборку.
3. Реализовать валидацию, типизацию, сортировку, фильтрацию и плоское представление дерева.
4. Реализовать виртуальный grid, управление колонками, выделение, итоги и мост 1С.
5. Добавить unit- и browser-тесты, выполнить полный гейт.
6. Документировать API/интеграцию и закрыть спецификацию.

## 2. Открытые вопросы

Нет. Продуктовые решения согласованы в плане реализации.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-14 | Vanilla JavaScript и собственный grid | Совместимость со старым WebKit и отсутствие runtime-зависимостей |
| 2026-09-14 | Один минифицированный HTML | Прямая загрузка в поле 1С без внешних файлов |
| 2026-09-14 | Строгий JSON | Безопасность и однозначная диагностика |
| 2026-09-14 | Сортировка только среди соседей | Сохранение структуры дерева |
| 2026-09-14 | Итоги только по видимым узлам | Соответствие текущему представлению пользователя |
| 2026-09-14 | Экспорт передаёт пустой payload | 1С сама владеет экспортом исходных данных |
| 2026-09-14 | Состояние только в памяти | Межсессионное хранение не входит в область задачи |

## 4. Результаты проверки

- 11 unit-тестов модели данных;
- headless Chromium smoke для нескольких таблиц, дерева, виртуализации 10 000 узлов и интерактивных сценариев;
- production-гейты автономности HTML и синтаксиса ES2015;
- полевой прогон в 1С оставлен пользователю по чек-листу из `docs/1c-integration.md`.
