# wrap-text-toolbar-group: отдельная группа кнопки переноса текста

## 1. Контекст и проблема

Кнопка переноса текста находится в одной группе с кнопкой `Колонки`, поэтому между ними нет визуального
разделителя.

## 2. Область изменений

Изменяется только группировка команд общей панели и соответствующий browser smoke-тест.

## 3. Поведение

- Кнопка `Колонки`, кнопка переноса текста и группа `Свернуть все`/`Развернуть все` находятся в трёх
  последовательных группах.
- Перед группой переноса и перед группой свернуть/развернуть показываются штатные разделители панели.
- Положение, пиктограмма, состояние и логика кнопки переноса не меняются.

## 4. Публичные контракты

Публичные функции, данные, настройки и события 1С не меняются.

## 5. Критерии приёмки

- [x] Между `Колонки` и кнопкой переноса виден разделитель.
- [x] Между кнопкой переноса и командами свернуть/развернуть виден разделитель.
- [x] Полный тестовый гейт проходит.

## 6. Вне области

- Изменение поведения переноса текста или остальных команд панели.
