# custom-context-menu-events: Пользовательские события контекстного меню

## 1. Контекст и проблема

Встроенное контекстное меню управляет только состоянием просмотрщика. Интеграции с 1С нужен способ добавлять
собственные команды и получать при их выборе значение ячейки, включая `ref` ссылочного значения.

## 2. Область изменений

Добавляется публичная регистрация пользовательских пунктов, их вывод в контекстном меню ячеек данных, отправка
события через существующий мост, browser-тесты и документация интеграции.

## 3. Поведение

### 3.1. Основной сценарий

- `addContextMenuItem(title, eventName)` добавляет один пункт без дедупликации.
- Пункты выводятся после штатных команд в порядке регистрации только для ячеек данных. Для номера строки они не
  выводятся.
- При выборе пользовательского пункта меню закрывается, после чего мост отправляет заданное событие.
- Для строки, числа, boolean и `null` payload равен `{ value: исходноеЗначение }`.
- Для `{ label, ref }` payload равен `{ value: label, ref: ref }`.
- Регистрация сохраняется при `setData`, но очищается вместе с приложением при `destroy` и повторном `init`.

### 3.2. Граничные случаи и ошибки

- До инициализации приложения и при аргументах, которые не являются непустыми строками, метод возвращает `false`
  и ничего не регистрирует.
- Успешная регистрация возвращает `true`. Повторяющиеся названия и имена событий разрешены.
- Тип обычного значения, `ref` и имя события не преобразуются.
- Название пункта выводится через `textContent`; пользовательский HTML не вставляется.

## 4. Публичные контракты

На `window` добавляется функция:

```js
addContextMenuItem(title, eventName) // boolean
```

Новые события сохраняют общий контракт `{ event, params }` в `window.events_queue`. Формат `Data`, остальные
публичные функции и штатные события не меняются.

## 5. Критерии приёмки

- [x] Несколько пунктов отображаются после штатных команд в порядке регистрации.
- [x] Для простых и ссылочных ячеек формируется документированный payload с исходными типами значений.
- [x] Пользовательские пункты отсутствуют в меню номера строки.
- [x] Регистрация переживает `setData`, но не `destroy` или повторный `init`.
- [x] Некорректные вызовы возвращают `false`, а HTML-подобное название отображается как текст.
- [x] Штатные команды и события не изменены; полный локальный гейт проходит.

## 6. Вне области

- Удаление, очистка и редактирование зарегистрированных пунктов.
- Передача таблицы, строки, колонки или других метаданных ячейки.
- Хранение регистрации вне памяти экземпляра приложения.
