# custom-context-menu-events: план реализации и решения

## 1. План реализации

1. Добавить в экземпляр приложения список зарегистрированных команд и метод регистрации с валидацией аргументов.
2. Дополнить меню ячейки данных пользовательскими командами и сформировать плоский payload значения.
3. Экспортировать `addContextMenuItem` непосредственно на `window`.
4. Расширить browser smoke сценариями API, жизненного цикла, безопасности текста и событий для всех типов ячеек.
5. Обновить документацию API и интеграции 1С, выполнить `npm test`.
6. Перевести спецификацию в `done` и перенести каталог в `specs/done/`.

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-15 | Регистрировать пункты по одному через `addContextMenuItem(title, eventName)` | Соответствует сценарию динамического добавления из 1С |
| 2026-09-15 | Передавать `{ value }` и добавлять `ref` на верхнем уровне для ссылки | Упрощает обработку payload во встроенном языке |
| 2026-09-15 | Хранить регистрацию в экземпляре приложения | `setData` не меняет настройки интеграции, а `init` создаёт чистый экземпляр |
| 2026-09-15 | Показывать команды после штатных только для ячеек данных | Номер строки не имеет исходного значения ячейки |
