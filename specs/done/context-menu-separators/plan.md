# context-menu-separators: план реализации и решения

## 1. План реализации

1. Заменить отдельный список пользовательских команд упорядоченным списком элементов меню и добавить метод
   регистрации разделителя.
2. При построении меню разбивать пользовательские команды на непустые группы через существующий механизм
   `appendMenuGroup`.
3. Экспортировать `addContextMenuSeparator` непосредственно на `window`.
4. Расширить browser smoke сценариями порядка, нормализации лишних разделителей и жизненного цикла API.
5. Обновить документацию API и интеграции 1С, выполнить `npm test`.
6. Перевести спецификацию в `done` и перенести каталог в `specs/done/context-menu-separators/`.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-17 | Использовать `addContextMenuSeparator()` без аргументов | Сохраняет простой пошаговый API регистрации меню из 1С |
| 2026-09-17 | Хранить команды и разделители в одной последовательности | Гарантирует порядок, заданный чередованием вызовов API |
| 2026-09-17 | Представлять разделитель границей непустых групп | Переиспользует штатную разметку и исключает лишние линии |
| 2026-09-17 | Сохранять регистрацию в экземпляре `ViewerApp` | Жизненный цикл совпадает с существующими пользовательскими командами |

Реализация завершена; unit-тесты, автономная production-сборка, проверка ES2015 и browser smoke пройдены.
