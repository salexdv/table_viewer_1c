# context-menu-separators: Пользовательские разделители контекстного меню

## 1. Контекст и проблема

Публичный метод `addContextMenuItem` позволяет интеграции с 1С добавлять команды в одну пользовательскую группу
контекстного меню. Разделить связанные команды на несколько визуальных групп через публичный API нельзя, хотя
штатные группы меню уже разделяются линиями.

## 2. Область изменений

Добавляется регистрация пользовательских разделителей, их совместный упорядоченный вывод с пользовательскими
командами, browser-тесты и документация JavaScript API и интеграции с 1С.

## 3. Поведение

### 3.1. Основной сценарий

- `addContextMenuSeparator()` регистрирует позицию разделения между пользовательскими командами и возвращает
  `true`.
- Вызовы `addContextMenuItem` и `addContextMenuSeparator` формируют одну упорядоченную последовательность.
- При открытии контекстного меню ячейки данных разделитель начинает новую пользовательскую группу. Группы
  выводятся после штатных команд в порядке регистрации.
- Пользовательские разделители, как и пользовательские команды, не выводятся для ячейки номера строки.
- Регистрация сохраняется при `setData`, но очищается вместе с приложением при `destroy` и повторном `init`.

### 3.2. Граничные случаи и ошибки

- Разделители до первой команды, после последней команды и несколько разделителей подряд не создают ведущих,
  замыкающих или сдвоенных линий.
- Если пользовательские команды не зарегистрированы, вызовы разделителя не меняют вид меню.
- До инициализации приложения и после `destroy` публичный метод возвращает `false`.
- Метод не принимает обязательных аргументов; переданные лишние аргументы игнорируются по правилам JavaScript.

## 4. Публичные контракты

На `window` добавляется функция:

```js
addContextMenuSeparator() // boolean
```

Контракты `addContextMenuItem`, данных, Settings и событий 1С не меняются. Production-сборка остаётся одним
автономным `dist/index.html`.

## 5. Критерии приёмки

- [x] Разделитель между двумя пользовательскими командами выводит их в двух группах с одной линией между ними.
- [x] Порядок команд и разделителей соответствует порядку вызовов публичных методов.
- [x] Ведущие, замыкающие и повторяющиеся пользовательские разделители не создают лишних линий.
- [x] Пользовательские элементы отсутствуют в меню номера строки.
- [x] Регистрация переживает `setData`, но не `destroy` или повторный `init`.
- [x] API и пример вызова из 1С документированы; полный локальный гейт проходит.

## 6. Вне области

- Удаление, очистка и редактирование зарегистрированных команд или разделителей.
- Разделители внутри штатных подменю.
- Отдельная настройка внешнего вида пользовательского разделителя.
