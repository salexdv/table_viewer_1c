# optional-column-aggregates: Опциональные итоги колонок

## 1. Контекст и проблема

Сейчас для каждой числовой и процентной колонки по умолчанию рассчитывается сумма, а строка итогов всегда
занимает место в таблице. В большинстве сценариев итоги не нужны, поэтому лишние расчёты и подвал следует
отключить до явного выбора функции пользователем.

## 2. Область изменений

Изменяются начальное состояние функций итогов, меню выбора агрегата, отрисовка и компоновка строки итогов,
browser- и unit-тесты, а также документация поведения.

## 3. Поведение

### 3.1. Основной сценарий

- Для числовых и процентных колонок доступны `Нет`, `Сумма`, `Среднее`, `Минимум`, `Максимум` и `Количество`.
- По умолчанию для каждой колонки выбрано `Нет`.
- При выборе функции итогов подвал появляется и рассчитывает только явно выбранные агрегаты видимых колонок.
- Колонки со значением `Нет` имеют пустую ячейку в показанном подвале.
- Если итогов нет ни у одной видимой колонки, подвал скрыт, не участвует в расчёте высоты и агрегаты колонок
  не рассчитываются.
- Изменение последнего активного итога сразу показывает или скрывает подвал и обновляет компоновку таблицы.

### 3.2. Скрытые колонки

- Выбранная функция скрытой колонки сохраняется в состоянии документа.
- Итоги скрытых колонок не удерживают подвал видимым и не рассчитываются.
- При повторном показе колонки её функция восстанавливается, а подвал снова появляется.

### 3.3. Граничные случаи и ошибки

- Агрегаты по-прежнему учитывают только показанные строки и сохраняют существующее форматирование пустых
  наборов, чисел и процентов.
- Селектор агрегата выделенного диапазона не содержит `Нет`, поддерживает прежние пять функций и по умолчанию
  использует сумму.
- Все пользовательские значения выводятся только через `textContent`.

## 4. Публичные контракты

Формат `Data`, публичные функции на `window`, очередь `{ event, params }` и события 1С не меняются. Выбор итогов
остаётся только в памяти документа и сбрасывается при `init` или `setData`. Production остаётся единым автономным
`dist/index.html` уровня ES2015.

## 5. Критерии приёмки

- [ ] Начальное состояние каждой колонки равно `none`, меню показывает активный пункт `Нет`, подвал скрыт.
- [ ] Выбор функции показывает корректный итог, а отключение последней видимой функции скрывает подвал.
- [ ] Несколько функций работают независимо; отключение одной сохраняет подвал для остальных.
- [ ] Скрытие колонки с единственным итогом скрывает подвал, повторный показ восстанавливает его.
- [ ] Селектор агрегата выделения и публичные контракты не изменены.
- [ ] Unit- и browser-тесты проходят; сборка остаётся self-contained и совместимой с ES2015.

## 6. Вне области

- Сохранение выбранных итогов между загрузками документа.
- Изменение функций или начального агрегата выделенного диапазона.
- Добавление новых публичных функций или параметров входных данных.
