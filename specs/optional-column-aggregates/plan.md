# optional-column-aggregates: план реализации и решения

## 1. План реализации

1. Добавить отдельный вариант `Нет` для меню итогов колонок и изменить начальное состояние на `none`, не меняя
   набор агрегатов выделенного диапазона.
2. Определять наличие итогов среди видимых колонок, пропускать расчёты и строку подвала при их отсутствии,
   учитывать фактическое наличие подвала в высоте таблицы.
3. Обновлять подвал и компоновку сразу после выбора функции, сохраняя функцию при скрытии колонки.
4. Расширить unit- и browser-тесты начальными, комбинированными и сценариями скрытых колонок; обновить
   документацию и выполнить `npm test`.
5. Перевести спецификацию в `done` и перенести её в `specs/done/optional-column-aggregates/`.

## 2. Открытые вопросы

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-15 | Учитывать только итоги видимых колонок | Подвал не должен отображаться без доступного пользователю результата |
| 2026-09-15 | Сохранять функцию скрытой колонки | Временная настройка видимости не должна сбрасывать независимое состояние |
| 2026-09-15 | Не добавлять `Нет` в агрегаты выделения | Запрос относится только к итогам колонок |
| 2026-09-15 | Не рассчитывать неактивные и скрытые итоги | Исключает лишний проход по строкам в типичном сценарии |
