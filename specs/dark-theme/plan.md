# dark-theme: план реализации и решения

## 1. План реализации

1. Расширить модель Settings корневым полем `theme`, сохранив версию 1, строгую валидацию и атомарное применение.
2. Добавить состояние темы в приложение, публичный `setTheme`, класс документа и доступную кнопку переключения.
3. Добавить совместимые со старым WebKit явные CSS-переопределения тёмной палитры без CSS-переменных.
4. Обновить документацию JavaScript API и интеграции с 1С.
5. Покрыть контракт unit/browser-тестами, выполнить `npm test`, завершить и перенести спецификацию.

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-16 | Использовать `setTheme('light' | 'dark')` | Контракт остаётся расширяемым и явно валидируемым |
| 2026-09-16 | Хранить тему в Settings v1 | Тема переносится вместе с существующим снимком без отдельного формата |
| 2026-09-16 | Добавить компактную кнопку в отдельную группу панели | Тема доступна пользователю и не смешивается с командами таблиц |
| 2026-09-16 | Применять класс `theme-dark` к `html` | Класс охватывает страницу и все фиксированные popup без перерисовки |
| 2026-09-16 | Не использовать CSS custom properties | Сохраняется совместимость с WebKit целевого окружения 1С |
