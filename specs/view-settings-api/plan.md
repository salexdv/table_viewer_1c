# view-settings-api: план реализации и решения

## 1. План реализации

1. Расширить разбор данных идентификаторами и встроенными настройками, добавить чистую валидацию, разрешение
   целей, сериализацию снимка и атомарное применение patch в модели.
2. Добавить `columnOrder` в состояние и использовать его в компоновке после закреплённых колонок.
3. Подключить встроенные настройки к `load`, реализовать `getSettings`/`setSettings` и экспортировать их на
   `window`.
4. Обновить JavaScript API и руководство интеграции с 1С.
5. Покрыть контракт unit/browser-тестами, выполнить `npm test`, завершить и перенести спецификацию.

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-15 | Возвращать настройки JSON-строкой | Надёжно передаётся между старым WebKit и 1С |
| 2026-09-15 | Применять `setSettings` как атомарный patch | Позволяет менять одно свойство и восстанавливать полный снимок тем же методом |
| 2026-09-15 | Использовать необязательные стабильные `id` с индексным fallback | Сохраняет совместимость и переживает перестановку данных |
| 2026-09-15 | Сохранять глобальный и все колонковые фильтры | Восстанавливает фактически видимый набор строк |
| 2026-09-15 | Не сохранять закрепление и не добавлять UI порядка | Удерживает изменение в согласованных границах |
