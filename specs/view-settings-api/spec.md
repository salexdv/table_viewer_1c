# view-settings-api: API сохранения и восстановления настроек представления

## 1. Контекст и проблема

Настройки масштаба, колонок и фильтров сейчас существуют только в памяти документа и сбрасываются при новой
загрузке данных. Интеграции 1С нужен переносимый JSON-снимок, который можно сохранить, передать вместе с данными
или применить отдельным вызовом API.

## 2. Область изменений

- Обратно совместимые идентификаторы таблиц и колонок во входном формате.
- Единый формат полного снимка и частичного patch настроек.
- Публичные функции `getSettings` и `setSettings`.
- Базовый порядок колонок, задаваемый через JSON/API.
- Документация и unit/browser-проверки нового контракта.

## 3. Поведение

### 3.1. Основной сценарий

- `Data.settings` применяется после создания состояния таблиц по умолчанию.
- `getSettings()` возвращает строгую JSON-строку версии 1 с глобальным поиском и полным состоянием масштаба,
  порядка, видимости, ширины, агрегатов и фильтров колонок.
- `setSettings(settingsOrJson)` принимает объект или JSON-строку и атомарно применяет переданные поля как patch.
- Таблицы и колонки сопоставляются по стабильному `id`, а старые данные без `id` — по исходному индексу.
- Если одновременно переданы `id` и `index`, используется только `id`. Отсутствующие цели пропускаются с
  предупреждением, без применения по резервному индексу.
- Неполный `columnOrder` переносит найденные колонки в начало в заданном порядке; остальные сохраняют текущий
  относительный порядок. Строка в порядке означает `id`, число — исходный индекс.
- После успешного применения закрываются панели и очищается выделение. Изменение фильтров дополнительно очищает
  временно скрытые диапазоны строк.

### 3.2. Формат и валидация

- Колонка задаётся прежней строкой либо объектом `{ id, name }`; таблица может иметь строковый `id`.
- Идентификаторы непустые и уникальные: таблицы — в документе, колонки — внутри таблицы.
- Масштаб лежит в диапазоне 50–200 с шагом 10; ширина — конечное число не меньше 60 логических пикселей.
- Агрегат равен `none`, `sum`, `average`, `min`, `max` или `count`.
- Фильтр содержит строку `text`, boolean `exact` и `values`: `null` либо массив строк. `filter: null` очищает
  фильтр целиком; `values: []` является активным пустым выбором.
- Синтаксическая или типовая ошибка отклоняет весь patch без частичных изменений. Неизвестное поле также является
  ошибкой. Неизвестная цель и агрегат, несовместимый с текущим типом колонки, пропускаются с предупреждением.
- Полный снимок содержит `version: 1`; patch может не содержать `version`, но другое значение отклоняется.

### 3.3. Жизненный цикл

- `init` и `setData` сначала создают значения по умолчанию, затем применяют встроенный `Data.settings`.
- `setData` без настроек сохраняет прежнее поведение полного сброса состояния таблиц.
- Некорректные встроенные настройки являются ошибкой всего `Data`. Ошибка отдельного `setSettings` оставляет
  текущий интерфейс без изменений и записывается в консоль.
- Закреплённые колонки временно выводятся перед базовым порядком, но не входят в сохраняемый профиль.

## 4. Публичные контракты

```js
Column = string | { id: string, name: string }
Table = { id?: string, name: string, columns: Column[], rows: Row[] }
Data = { tables: Table[], settings?: Settings }

getSettings()                 // JSON string | false
setSettings(settingsOrJson)  // boolean
```

Полный снимок таблицы содержит её `id` при наличии, всегда содержит `index`, `scale`, `columnOrder` и полный
массив колонок. Колонка аналогично содержит `id` при наличии, исходный `index`, `visible`, `width`, `aggregate`
и `{ text, exact, values }`.

Формат событий 1С, очередь `{ event, params }` и production-контракт не меняются.

## 5. Критерии приёмки

- [ ] Старый входной формат работает без изменений, новый проверяет уникальность идентификаторов.
- [ ] Встроенные настройки и `setSettings` используют один формат и одинаковую валидацию.
- [ ] Полный снимок проходит round-trip без потери всех включённых настроек.
- [ ] Частичный patch не сбрасывает пропущенные поля и применяется атомарно.
- [ ] Сопоставление по `id`, индексный fallback, неполный порядок и отсутствующие цели работают по контракту.
- [ ] Все виды фильтров, масштабы, ширины, видимость и шесть режимов агрегата восстанавливаются.
- [ ] Unit/browser-тесты и production-проверки проходят на ES2015 single-file сборке.

## 6. Вне области

- UI для перетаскивания колонок.
- Сортировка, закрепление строк/колонок, раскрытие, выделение, скрытые строки, прокрутка и ширина номера строки.
- Настройки визуального представления значений ячеек.
