# Интеграция с 1С

## Подготовка HTML

1. Выполните `npm run build` и прочитайте `dist/index.html` как текст.
2. Сериализуйте структуру `{ tables: [...] }` в строгий JSON.
3. Замените в JSON каждый литеральный `<` на последовательность `\u003C`.
4. Замените маркер `_DATA_` подготовленным JSON и передайте результат в «Поле HTML документа».
5. После формирования документа приложение вызовет `init()` автоматически.

Кодирование `<` обязательно даже при доверенных данных: последовательность `</script>` внутри значения иначе
закроет контейнер JSON на уровне HTML до вызова `JSON.parse`. Не кодируйте весь JSON как HTML entities — содержимое
читается как текст и должно оставаться корректным JSON.

Упрощённый фрагмент на встроенном языке (имена процедур сериализации и реквизитов адаптируйте к конфигурации):

```bsl
ШаблонHTML = ПолучитьМакет("TableViewer").ПолучитьТекст();
JSONДанные = СериализоватьДанныеВJSON(ДанныеТаблиц);
JSONДанные = СтрЗаменить(JSONДанные, "<", "\u003C");
ГотовыйHTML = СтрЗаменить(ШаблонHTML, "_DATA_", JSONДанные);
Элементы.ПолеHTML.УстановитьТекст(ГотовыйHTML);
```

JSON должен быть строгим: только двойные кавычки, без комментариев и хвостовых запятых. Каждая строка должна
иметь ровно столько ячеек, сколько объявлено колонок. При нарушении контракта страница покажет путь ошибки.

## Вызов методов из 1С

После формирования документа получите его `defaultView` и вызывайте плоский API:

```bsl
Окно = Элементы.ПолеHTML.Документ.defaultView;
Окно.setTableCollapsed(0, Истина);
Окно.setTreeExpanded(1, Ложь);
Окно.expandAll();
Окно.addContextMenuItem("Открыть карточку", "EVENT_OPEN_CARD");
```

`addContextMenuItem` можно вызвать несколько раз. Команды появятся после штатных пунктов контекстного меню в
порядке регистрации. Они сохраняются при `setData`, но после повторного `init` их нужно зарегистрировать заново.

Если нужно обновить данные без повторной загрузки HTML, передайте в `setData` JSON-строку либо JS-объект,
созданный в контексте страницы. Самый переносимый вариант для старого WebKit — строка JSON:

```bsl
Окно.setData(JSONДанные);
```

Полный контракт методов находится в [документации API](api.md).

## Получение событий

В HTML всегда присутствует скрытая кнопка:

```html
<button id="event-button" hidden></button>
```

`sendEvent` помещает объект в `window.events_queue`. Через 10 мс кнопка получает программный клик; её JS-обработчик
извлекает первый элемент очереди и записывает его в пользовательское поле `eventData1C` объекта события клика.
Обработчик события HTML-поля в 1С должен прочитать это поле и разобрать объект:

```bsl
// Сигнатура обработчика зависит от вида формы и версии клиента.
Процедура ПолеHTMLСобытие(Элемент, ДанныеСобытия, СтандартнаяОбработка)
    Если ДанныеСобытия.eventData1C = Неопределено Тогда
        Возврат;
    КонецЕсли;

    Данные = ДанныеСобытия.eventData1C;
    Если Данные.event = "EVENT_ON_LINK_CLICK" Тогда
        // Данные.params.label — представление ссылки.
        // Данные.params.href  — исходное значение ref, например e1cib/data/...
        ОбработатьПереходПоСсылке(Данные.params.href);
    ИначеЕсли Данные.event = "EVENT_OPEN_CARD" Тогда
        // Для ссылочной ячейки value содержит label, а ref — исходную ссылку.
        // Для остальных ячеек передаётся только value с исходным типом.
        ОткрытьКарточкуПоЗначению(Данные.params.value, Данные.params.ref);
    ИначеЕсли Данные.event = "EVENT_EXPORT" Тогда
        // Payload намеренно пустой: экспортом исходных данных владеет 1С.
        ВыполнитьЭкспорт();
    КонецЕсли;
КонецПроцедуры
```

Точные имена параметров обработчика могут отличаться между обычными/управляемыми формами и клиентами. Не ищите
payload в DOM: источником является именно `eventData1C` объекта текущего клика. Очередь FIFO предотвращает потерю
порядка при нескольких быстрых событиях.

### События

```js
{
  event: 'EVENT_ON_LINK_CLICK',
  params: { label: 'Заявка 000000001', href: 'e1cib/data/Документ...ref=...' }
}
```

```js
{ event: 'EVENT_EXPORT', params: {} }
```

Пользовательский пункт для обычной ячейки формирует событие вида:

```js
{ event: 'EVENT_OPEN_CARD', params: { value: 42 } }
```

Для ссылочной ячейки `ref` добавляется на верхний уровень `params`:

```js
{ event: 'EVENT_OPEN_CARD', params: { value: 'Заявка 000000001', ref: 'e1cib/data/Документ...ref=...' } }
```

Приложение не открывает `ref` самостоятельно и не формирует экспортируемый файл.

## Ручной чек-лист для 1С 8.3.14+

- [ ] `dist/index.html` после подстановки загружается без обращения к сети и без ошибок консоли.
- [ ] Несколько таблиц отображаются друг под другом, плоская таблица и дерево различаются корректно.
- [ ] Таблица с 10 000 узлов плавно прокручивается; DOM-пул ограничен и переиспользуется при прокрутке.
- [ ] Сортировка проходит цикл возрастание → убывание → исходный порядок и перенумеровывает строки.
- [ ] Фильтр колонки и глобальный поиск работают вместе; найденный потомок виден со своими предками.
- [ ] Список значений колонки виртуализирован, поддерживает поиск, массовый выбор и объединяется с текстовым фильтром.
- [ ] Очистка фильтра восстанавливает пользовательское раскрытие ветвей.
- [ ] Начальные ширины подобраны по содержимому, свободное место заполнено пропорционально; ручной resize работает.
- [ ] Одна видимая большая таблица занимает доступную высоту окна, короткая сохраняет естественную высоту.
- [ ] Колонки скрываются и фиксируются; несколько фиксаций сохраняют порядок выбора.
- [ ] Строки фиксируются и учитываются в итогах один раз.
- [ ] Контекстный «Отбор по значению» заменяет фильтр выбранной колонки точным значением.
- [ ] Пользовательские пункты меню передают исходное значение ячейки и `ref` ссылочной ячейки в событии 1С.
- [ ] Плоская таблица скрывает строки до/после выбранной и возвращает их через верхний/нижний маркер.
- [ ] Протягивание и Shift-клик создают прямоугольное выделение; кнопка `Ʃ` показывает пять базовых числовых функций.
- [ ] Выбранные функции итогов числовых и процентных колонок рассчитаны по реально показанным узлам.
- [ ] Масштаб каждой таблицы меняется от 50% до 200% с шагом 10%.
- [ ] Пиктограммные команды раскрывают и сворачивают отдельное дерево и все таблицы вместе.
- [ ] Клик ссылочной ячейки передаёт `EVENT_ON_LINK_CLICK` с ожидаемыми `label` и `href`.
- [ ] Временно скрытая кнопка «Экспорт» остаётся в DOM, а `sendEvent('EVENT_EXPORT', {})` передаёт событие.
- [ ] Повторный `setData` полностью заменяет таблицы и сбрасывает состояние интерфейса.
- [ ] HTML с незаменённым `_DATA_` показывает по центру `Ожидение данных...`, а не диагностическую ошибку.
- [ ] Ошибочный JSON показывает понятный путь ошибки и не исполняет содержимое ячеек как HTML.

Результат полевого прогона рекомендуется фиксировать вместе с версией платформы, типом клиента и его WebKit.
