# Публичный JavaScript API

Все методы установлены непосредственно на `window`. Из 1С они доступны через `Документ.defaultView`, где
`Документ` — DOM-документ поля HTML. Методы не выбрасывают наружу ошибки валидации: возвращают `false`, выводят
диагностику в интерфейсе и записывают исходную ошибку в консоль.

## Типы данных

```js
// string | number | boolean | null | { label: string, ref: string }
Cell

Row   = { columns: Cell[], children?: Row[] }
Table = { name: string, columns: string[], rows: Row[] }
Data  = { tables: Table[] }
```

Индекс таблицы во всех методах начинается с нуля.

## `init(data?)`

Идемпотентно создаёт приложение заново. Предыдущий экземпляр уничтожается вместе с обработчиками и состоянием.

- `data` — необязательный объект `Data` или строка строгого JSON;
- без аргумента читает текст из `<script id="data" type="application/json">`;
- возвращает `true` после успешной инициализации, иначе `false`;
- незаменённый `_DATA_` считается состоянием ожидания: метод возвращает `false`, показывает `Ожидение данных...`
  и не записывает ошибку в консоль;
- если `#app` отсутствует, возвращает `false` без построения интерфейса.

```js
window.init({ tables: [] });
window.init('{"tables":[]}');
```

## `setData(dataOrJson)`

Заменяет весь набор данных и сбрасывает состояние таблиц текущей сессии: текстовые фильтры и фильтры значений,
сортировку, видимость и ширину колонок, функции итогов (для колонок — `Нет`), фиксацию, раскрытие, скрытые
диапазоны, масштаб и выделение.
Если приложение ещё не создано, действует как `init(dataOrJson)`.

- `dataOrJson` — объект `Data` или строка строгого JSON;
- возвращает `true` при успехе и `false` при ошибке формата.

```js
window.setData({
  tables: [{ name: 'Остатки', columns: ['Товар', 'Количество'], rows: [] }]
});
```

Ошибка содержит JSONPath-подобный путь, например:

```text
$.tables[0].rows[2].columns: ожидалось 4 ячеек, получено 3
```

## Настройка отображения значений

Настройки этого раздела меняют только текст, `title` и цвет видимых ячеек. Поиск, фильтры, сортировка, списки
значений, типы колонок, ширины, итоги и события используют исходные данные. Настройки сохраняются при `setData`,
но сбрасываются при `destroy` или повторном `init`.

Цвет передаётся непустой валидной CSS-строкой, например `red`, `#c62828` или `rgb(198, 40, 40)`. Некорректный
цвет возвращает `false` и не меняет действующую настройку.

### `setNegativeNumberColor(colorOrNull)`

Задаёт цвет отрицательных JSON-чисел и строк, распознанных как числа или проценты: `-1`, `-1,5`, `-10%`.
Колонка не обязана быть целиком числовой. Без вызова отрицательные значения отдельно не выделяются; `null`
отключает заданный цвет.

```js
window.setNegativeNumberColor('#c62828');
window.setNegativeNumberColor(null);
```

### `setCellValuePresentation(value, presentationOrNull)`

Задаёт представление точного скалярного значения `string | number | boolean | null`. Тип является частью
сравнения, поэтому число `0` и строка `"0"` настраиваются независимо. Представлением может быть любая строка,
включая пустую; пользовательский HTML всегда выводится как текст. `null` во втором аргументе удаляет правило.

```js
window.setCellValuePresentation('0', '<0>');
window.setCellValuePresentation('0', null);
```

### `setCellValueColor(value, colorOrNull)`

Задаёт цвет точного скалярного значения. Правило имеет приоритет над общим цветом отрицательных. `null` во
втором аргументе удаляет правило.

```js
window.setCellValueColor('0', '#6d7d91');
window.setCellValueColor('0', null);
```

### `setShowEmptyReferences(enabled)`

Включает специальный вывод ссылок, чей `ref` заканчивается на 32 нуля. Каноническая ссылка
`e1cib/data/<тип>?ref=00000000000000000000000000000000` показывается некликабельным текстом
`<<тип> (пустая)>`, независимо от `label`. Для другого формата с тем же суффиксом выводится `<пустая ссылка>`.
При отключении восстанавливается обычный вывод `label` и обработка клика.

```js
window.setShowEmptyReferences(true);
window.setShowEmptyReferences(false);
```

### `setEmptyReferenceColor(colorOrNull)`

Задаёт цвет текста пустых ссылок. Исходный цвет — `#6d7d91`; `null` возвращает его. Вызов не включает показ
пустых ссылок — для этого отдельно используется `setShowEmptyReferences(true)`.

```js
window.setEmptyReferenceColor('#78909c');
window.setEmptyReferenceColor(null);
```

Все пять методов применяют изменение немедленно и возвращают `true` при успехе. До создания приложения или при
некорректных аргументах возвращается `false`.

## `setTableCollapsed(tableIndex, collapsed)`

Сворачивает или раскрывает тело одной таблицы.

- `tableIndex` — индекс таблицы с нуля; строковое число также принимается;
- `collapsed` — значение, приводимое к boolean;
- возвращает `true`, если таблица существует, иначе `false`.

```js
window.setTableCollapsed(0, true);
window.setTableCollapsed(0, false);
```

## `setTreeExpanded(tableIndex, expanded)`

Меняет состояние всех ветвей указанной таблицы. При `false` сворачивает каждый узел с потомками, при `true`
раскрывает все узлы. Для плоской таблицы вызов безопасен и возвращает `true` при корректном индексе.

```js
window.setTreeExpanded(1, false);
window.setTreeExpanded(1, true);
```

## `expandAll()` и `collapseAll()`

`expandAll()` раскрывает тела всех таблиц и все ветви деревьев. `collapseAll()` сворачивает тела таблиц и
помечает все ветви свёрнутыми. Оба метода очищают выделение и возвращают `true`; до инициализации возвращают
`false`.

```js
window.expandAll();
window.collapseAll();
```

## Контекстное меню строк

Для ячейки данных меню начинается с `Отбор по значению`, затем показывает отдельные группы фиксации строки и
колонки и подменю `Сворачивание`. В нём доступны `Свернуть выделенные`, `Свернуть до` и `Свернуть после`.
Скрытый последовательный диапазон заменяется кнопкой `Показать N скрытых строк`, которая восстанавливает только
этот диапазон.

В дереве команды `до/после` действуют на текущий плоский список видимых узлов. Дополнительное подменю
`Уровень группировки` содержит уровни от корневого до максимальной глубины: уровень K показывает строки уровней
1…K, а последний пункт раскрывает всё дерево.

## `addContextMenuItem(title, eventName)`

Добавляет пользовательский пункт в последнюю, отделённую разделителем группу контекстного меню ячеек данных.
Пункты следуют после штатных команд в порядке регистрации и не показываются для ячейки номера строки.

- `title` и `eventName` — непустые строки;
- успешный вызов возвращает `true`, некорректные аргументы или отсутствие приложения — `false`;
- одинаковые пункты разрешены и не объединяются;
- регистрация сохраняется при `setData`, но очищается при `destroy` и повторном `init`.

```js
window.addContextMenuItem('Открыть карточку', 'EVENT_OPEN_CARD');
```

Выбор пункта передаёт имя события без преобразований. Для простой ячейки payload имеет вид `{ value }` и
сохраняет исходный тип значения. Для ссылочной ячейки `{ label, ref }` формируется `{ value: label, ref }`.

```js
{ event: 'EVENT_OPEN_CARD', params: { value: 'Заявка 000000001', ref: 'e1cib/data/Документ...' } }
```

## `sendEvent(eventName, eventParams)`

Добавляет `{ event, params }` в конец `window.events_queue` и через 10 мс программно нажимает скрытую кнопку
`#event-button`. Пропущенный `eventParams` заменяется пустым объектом. Возвращает `true` после постановки в
очередь и `false`, если приложение не инициализировано.

```js
window.sendEvent('MY_EVENT', { id: 42 });
```

Штатные события приложения:

| Событие | `params` | Когда формируется |
| --- | --- | --- |
| `EVENT_ON_LINK_CLICK` | `{ label: string, href: string }` | Клик по ячейке `{ label, ref }`; `href` равен `ref` |
| `EVENT_EXPORT` | `{}` | Зарезервированная кнопка «Экспорт» или явный `sendEvent`; кнопка временно скрыта |

События обрабатываются FIFO: один клик кнопки передаёт один элемент очереди.

## `fireEvent()`

Немедленно нажимает `#event-button`. Следующий элемент очереди, если он есть, попадёт в
`clickEvent.eventData1C`. Метод не добавляет новое событие и возвращает `true` после инициализации, иначе `false`.

```js
window.events_queue.push({ event: 'MY_EVENT', params: {} });
window.fireEvent();
```

## `destroy()`

Снимает обработчики документа и окна, отменяет отложенные поиск и перерисовку, закрывает меню, отключает мост и
очищает `#app`. Данные очереди `window.events_queue` не удаляет. Возвращает `true` при уничтожении существующего
экземпляра и `false`, если приложение не было инициализировано.

```js
window.destroy();
window.init(newData);
```

## Автоматический запуск

Скрипт устанавливает API сразу и вызывает `init()` на `DOMContentLoaded` либо немедленно, если документ уже
загружен. В HTTP-режиме разработки незаменённый `_DATA_` показывает демонстрационный набор. В локальном HTML и
поле 1С незаменённый маркер считается ошибкой, чтобы тестовые данные не попали пользователю незаметно.
