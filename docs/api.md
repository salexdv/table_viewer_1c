# Публичный JavaScript API

Все методы установлены непосредственно на `window`. Из 1С они доступны через `Документ.defaultView`, где
`Документ` — DOM-документ поля HTML. Методы не выбрасывают наружу ошибки валидации: возвращают `false`, выводят
диагностику в интерфейсе и записывают исходную ошибку в консоль.

## Типы данных

```js
// string | number | boolean | null | { label: string, ref: string }
Cell

Row   = { columns: Cell[], children?: Row[] }
Table = { name: string, columns: string[], rows: Row[] }
Data  = { tables: Table[] }
```

Индекс таблицы во всех методах начинается с нуля.

## `init(data?)`

Идемпотентно создаёт приложение заново. Предыдущий экземпляр уничтожается вместе с обработчиками и состоянием.

- `data` — необязательный объект `Data` или строка строгого JSON;
- без аргумента читает текст из `<script id="data" type="application/json">`;
- возвращает `true` после успешной инициализации, иначе `false`;
- незаменённый `_DATA_` считается состоянием ожидания: метод возвращает `false`, показывает `Ожидение данных...`
  и не записывает ошибку в консоль;
- если `#app` отсутствует, возвращает `false` без построения интерфейса.

```js
window.init({ tables: [] });
window.init('{"tables":[]}');
```

## `setData(dataOrJson)`

Заменяет весь набор данных и сбрасывает состояние таблиц текущей сессии: текстовые фильтры и фильтры значений,
сортировку, видимость и ширину колонок, функции итогов (для колонок — `Нет`), фиксацию, раскрытие, скрытые
диапазоны, масштаб и выделение.
Если приложение ещё не создано, действует как `init(dataOrJson)`.

- `dataOrJson` — объект `Data` или строка строгого JSON;
- возвращает `true` при успехе и `false` при ошибке формата.

```js
window.setData({
  tables: [{ name: 'Остатки', columns: ['Товар', 'Количество'], rows: [] }]
});
```

Ошибка содержит JSONPath-подобный путь, например:

```text
$.tables[0].rows[2].columns: ожидалось 4 ячеек, получено 3
```

## `setTableCollapsed(tableIndex, collapsed)`

Сворачивает или раскрывает тело одной таблицы.

- `tableIndex` — индекс таблицы с нуля; строковое число также принимается;
- `collapsed` — значение, приводимое к boolean;
- возвращает `true`, если таблица существует, иначе `false`.

```js
window.setTableCollapsed(0, true);
window.setTableCollapsed(0, false);
```

## `setTreeExpanded(tableIndex, expanded)`

Меняет состояние всех ветвей указанной таблицы. При `false` сворачивает каждый узел с потомками, при `true`
раскрывает все узлы. Для плоской таблицы вызов безопасен и возвращает `true` при корректном индексе.

```js
window.setTreeExpanded(1, false);
window.setTreeExpanded(1, true);
```

## `expandAll()` и `collapseAll()`

`expandAll()` раскрывает тела всех таблиц и все ветви деревьев. `collapseAll()` сворачивает тела таблиц и
помечает все ветви свёрнутыми. Оба метода очищают выделение и возвращают `true`; до инициализации возвращают
`false`.

```js
window.expandAll();
window.collapseAll();
```

## `sendEvent(eventName, eventParams)`

Добавляет `{ event, params }` в конец `window.events_queue` и через 10 мс программно нажимает скрытую кнопку
`#event-button`. Пропущенный `eventParams` заменяется пустым объектом. Возвращает `true` после постановки в
очередь и `false`, если приложение не инициализировано.

```js
window.sendEvent('MY_EVENT', { id: 42 });
```

Штатные события приложения:

| Событие | `params` | Когда формируется |
| --- | --- | --- |
| `EVENT_ON_LINK_CLICK` | `{ label: string, href: string }` | Клик по ячейке `{ label, ref }`; `href` равен `ref` |
| `EVENT_EXPORT` | `{}` | Зарезервированная кнопка «Экспорт» или явный `sendEvent`; кнопка временно скрыта |

События обрабатываются FIFO: один клик кнопки передаёт один элемент очереди.

## `fireEvent()`

Немедленно нажимает `#event-button`. Следующий элемент очереди, если он есть, попадёт в
`clickEvent.eventData1C`. Метод не добавляет новое событие и возвращает `true` после инициализации, иначе `false`.

```js
window.events_queue.push({ event: 'MY_EVENT', params: {} });
window.fireEvent();
```

## `destroy()`

Снимает обработчики документа и окна, отменяет отложенные поиск и перерисовку, закрывает меню, отключает мост и
очищает `#app`. Данные очереди `window.events_queue` не удаляет. Возвращает `true` при уничтожении существующего
экземпляра и `false`, если приложение не было инициализировано.

```js
window.destroy();
window.init(newData);
```

## Автоматический запуск

Скрипт устанавливает API сразу и вызывает `init()` на `DOMContentLoaded` либо немедленно, если документ уже
загружен. В HTTP-режиме разработки незаменённый `_DATA_` показывает демонстрационный набор. В локальном HTML и
поле 1С незаменённый маркер считается ошибкой, чтобы тестовые данные не попали пользователю незаметно.
