# Table Viewer для 1С

Single-page просмотрщик таблиц и деревьев значений для встраивания в «Поле HTML документа» 1С.

Проект находится в разработке по спецификации [`specs/table-viewer/spec.md`](specs/table-viewer/spec.md).
Production-сборка создаёт один автономный `dist/index.html`.
